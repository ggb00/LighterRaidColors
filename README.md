# Lighter Raid Colors

Changes chat colors for **"Raid Leader"** and **"Raid Warnings"** from orange-red (`#FF4809`) to peach (`#FFDBB7`)\
The color changes are only applied while the addon is active, there are no permanent changes

For **World of Warcraft: Wrath of the Lich King (3.3.5a)**

<sup>Made with the help of AI.</sup>

# Installation

1. Download the addon by clicking the link below:
   - [Download Lighter Raid Colors](https://github.com/ggb00/LighterRaidColors/archive/refs/heads/main.zip)
2. Unzip the downloaded archive.
3. Rename the folder inside the zip from `LighterRaidColors-main` to `LighterRaidColors` (folder name should be the same as `.toc` file).
4. Move the `LighterRaidColors` folder to your World of Warcraft AddOns folder.
    - Example: `C:\World of Warcraft WotLK\Interface\AddOns`
5. If you have WoW open - restart the game for the addon to load in properly.
